# Java-Programs

Java practice workspace containing a small console calculator and a set of language exercises, kept as two IntelliJ projects.

## Projects

### `Calculator/`
A console calculator with its arithmetic logic separated into a `Calculators` class and a `Main` entry point.

### `Task/`
Exercises grouped by the concept they practise:

| Folder | Topic |
|---|---|
| `src/Array/` | Array handling |
| `src/Constructor/` | Constructors (worked through an `Account` and a `Library` example) |
| `src/Method/` | Method overloading |
| `src/Object/` | Objects and classes (`Student`, `Employee`) |

## Running

Open the `Calculator` or `Task` folder as a project in IntelliJ IDEA and run the `Main` class in that project.

## Notes

Coursework practice. The `.iml` and `.idea` files are committed so the projects open directly in IntelliJ.
